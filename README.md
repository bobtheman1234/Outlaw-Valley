# OUTLAW VALLEY: THE HOLLOW CROWN — v0.3 playable candidate

Independent Roblox free-roam PvE-first fantasy adventure. This project shares no code with Goblin Hunt.

## The place file

`Outlaw_Valley_Hollow_Crown_v03.rbxlx` is an editable Roblox Studio place file. Open from file and publish under your own Roblox account. Player-owned experiences automatically grant Godslayer to the experience's creator. The 100-Robux pass is not live until a pass is created in the Roblox Creator Dashboard and its numeric ID is set in `ReplicatedStorage.OutlawConfig.PassId`.

## Core mechanics built

- A connected valley with an explorable village, roads, forest bandit camp, swamp, observatory, ancient bridge, cave scenery and fortress, interiors and multiple landmarks.
- Eight weapon configurations: Rustfang starter sword, Ironbark crossbow, Thundermouth blunderbuss, Witchfire staff, Scrap Rattler, Boomstick explosive launcher, Soulrender secret sword, and Godslayer paid/creator entitlement.
- Eight enemy classes with HP bars: goblins, archers, bandits, wisps, wizards, knights, brutes and a Crownless Warden boss. R15 models are generated by Roblox when available; custom fallback rigs are assembled from parts.
- Enemies deal damage, flank, sidestep, cast projectiles, summon minions, use warning zones, dodge/teleport, and stagger when hit. Obstacles are detected by a raycast feeler, not full pathfinding.
- Boss changes moves and summons guards in later phases. Co-op players contributing at least 12% of a boss's HP can receive rewards even without the final blow.
- Three three-wave signal defenses. They require surviving and eliminating enemies, not just clicking a beacon.
- Three hidden crown relic altars with guardian fights. Claiming all three unlocks Soulrender.
- Eggs with a ten-minute wait (while you do other activities), which can hatch into a Hollow Fox companion that attacks nearby enemies.
- Expiring supply caches, bank, merchant shop, ammo refill, healing, day-night cycle and periodic world events.
- Multiplayer support with wilderness PvP. A PvP kill can transfer 25% of the victim's carried gold, while banked money and owned weapons remain safe.
- Godslayer: huge damage, penetrating visual, area damage and direct one-hit kills against players outside the safe town. Purchases verify ownership server-side. A live 100-Robux pass requires its creator dashboard ID.
- Q dodging with an enforced cooldown; finite ammo, reloading, weapon-specific firing, arcing bouncing Boomstick grenades, impact effects and explosion particles.

## Commands

- **M** — map
- **Q** — dodge
- **R** — reload current firearm
- **Click** — attack/use equipped weapon
- **E** — interact with prompts near merchants, chests, beacons, relics and nursery (Roblox default prompt key)

## Owner access

The game's *Roblox creator account* receives Godslayer without a pass. This is based on `game.CreatorType` and `game.CreatorId` after publishing. The configuration also supports explicit Roblox UserIds for group-owned games. In Studio, the test environment grants Godslayer for demonstration; this temporary test entitlement is explicitly excluded from persistent ownership saves.

## Testing and limitations

**Roblox Studio runtime, multiplayer playtest, visual quality and play duration have NOT been verified here.** We ran Lua syntax checks, executed pure-function purchase/loot/incubation tests, validated XML packaging, and ran structural contracts. These do not guarantee the player-facing result is fun or bug-free. Specific Creator Store models have **not** been imported: 0 vetted external mesh assets embedded. Environments use Roblox built-in geometry and materials, plus Roblox-generated R15 rigs. GUI proportions are desktop-first. Terrain is made with anchored parts rather than Roblox Terrain voxels. Enemy avoidance is a feeler rather than guaranteed PathfindingService navigation. The pass does not charge Robux until configured on your published experience.
