# Outlaw Valley: The Hollow Crown

New, independent Roblox free-roam PvE-first fantasy adventure. This repository is the canonical checkpoint location for development; not based on Goblin Hunt.

## Status

**Development in progress.** Gameplay has not been tested in Roblox Studio. Source code, editable Roblox `.rbxlx` and build notes will be committed as they are created and validated.

## Design constraints

- Connected free-roam world with dense settlements, landmarks, exploration and surprises.
- PvE focus: meaningful combat, real hit feedback, limited ammunition, enemies with different attacks, bosses, exploration.
- Multiplayer coop and optional PvP where direct hits from the Godslayer can one-shot players.
- Original player-facing systems: equipment, gold, loot, crafting, collectible eggs with incubation, quest encounters, and persistent progress.
- Godslayer game pass target: 100 Robux. Pass ID must be created in the Roblox Creator Dashboard; game grants weapon to verified owners and to the developer by UserId override.
- Save code and checkpoint notes to this repository; do not make unverified runtime promises.

## Validation truthfulness

Source syntax and simulated logic tests are distinct from real Roblox Studio playtesting. Any unresolved engine integration must be reported explicitly.
